# Fordham Community Church site

Single-page site for Fordham Community Church (fccbronx.org), 2439 Creston Avenue, Bronx.

- `index.html` is the whole site. No build step.
- Photos load from the church's existing photo host (images.squarespace-cdn.com). To use your own copies instead, put them in an `images/` folder and change the `src`/`srcset` URLs in `index.html`.
- Publish with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
